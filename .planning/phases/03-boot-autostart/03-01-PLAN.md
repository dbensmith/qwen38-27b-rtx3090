<objective>
Make the last-selected Compose profile survive a WSL2 reboot by installing a self-healing boot hook that follows the existing `/etc/wsl.conf [boot]` chezmoi wrapper convention (no systemd). The hook reads `.current-profile` (written by `switch.sh` after each successful switch), defaults to `batch` when nothing was ever chosen, and starts exactly that profile. Covers BOOT-01 (the hook), BOOT-02 (the `batch` default), and BOOT-03 (idempotent install).

Purpose: A reboot is the one failure `restart: unless-stopped` cannot cover — a fresh WSL2 session has no running containers. This phase gives the machine a boot hook, owned by the dotfiles repo like the existing `paseo-boot-start`, that restores the user's chosen profile automatically.

Output: the 045 chezmoi template (owner of `/usr/local/bin/local-llm-start` and the combined `[boot]` line), committed to the dotfiles repo; Task 1 proves the template renders (dry-run only — a real apply needs sudo, which is scoped out of the agent sandbox: RESEARCH A3, PATTERNS Shared Pattern 8) and commits it; Task 2 (human) runs the first real apply, proves D-11 idempotency, and proves the hook with a real `wsl --shutdown` + reopen reboot (D-12 — the only thing only a human can do).
</objective>
